# CPlusHomeRecord（家の記録）

Ultima Online Enhanced Client のカスタム UI「CLifeUI」に足して使う、非公式の追加機能です。

**CLifeUI が必須です。** CLifeUI の部品を使って動くので、CLifeUI を入れていない状態や、ほかのカスタム UI では動きません。先に CLifeUI を入れて、動くことを確かめてから入れてください。CLifeUI は、作者様の公式ページ（<https://uo.clife.work/uosa-custom-ui-clifeui/>）の手順で入れてください。

自分の家でロックダウンした箱を開いて閉じると、その中身をファイルに記録します。記録は、PC のブラウザで開く検索ページで探せます。「あのアイテムはどの家の、どの箱に入れたか」を調べるためのものです。

## 2 つの zip

| zip | 中身 | 置く場所 |
|---|---|---|
| `CPlusHomeRecord-0.3.zip` | ゲームの中で記録する部分（モジュール） | CLifeUI の `ClfMods` フォルダの中 |
| `CPlusHomeViewer-0.3.zip` | 記録を探す検索ページと、その読み出し役（ビューアー） | ゲームのフォルダの外の、好きな場所（ドキュメントなど） |

記録はモジュールだけで取れます。記録を探すには、ビューアーも入れてください。

**詳しい入れ方と使い方は、zip の中の `使い方.html` をブラウザで開いてください。**

## できること

- 自分の家の箱の中身を、箱を閉じたときに記録する（宝石箱・スクロールブック・デイビーズのロッカーにも対応）
- 検索ページで、アイテムの名前・プロパティ・家・階・箱の種類から探す
- 探したアイテムのある箱まで、ゲームの中で矢印と枠で案内する

## 記録のファイルについて

データベースは使いません。箱を閉じるたびに、その箱の記録ファイルが 1 本増えます（1 本はふつう数 KB、大きな箱でも数十 KB。記録 1,000 本でおよそ 8 MB）。検索ページは、箱ごとにいちばん新しい記録を使います。古い記録はたまっていくので、ときどき検索ページの［整理削除］で消してください。

## メモリ使用量について

記録が動くのは、登録した家の中で箱を開け閉めしたときだけです。常に動いている処理はありません。検索ページの読み出し役（PowerShell の窓）は、検索ページを閉じてから 10 分待つと自動で止まります。すぐ止めたいときは、その窓を自分で閉じます。作者の環境での実測は `使い方.html` の「メモリ使用量について」にあります。

## このソフトがゲームに対してしないこと

- ゲームのクライアントを書き換えません。Enhanced Client が公式に用意しているカスタム UI の仕組みの中で動きます。
- ゲームのメモリを外から読んだり書いたりしません。
- ゲームとサーバの間の通信を、読んだり書き換えたりしません。このソフトからサーバへ何かを送ることもありません。
- ゲームの操作を自動で行いません。ボタンを押す・アイテムを使う・キャラクターを動かすといった操作はせず、家の中の開いた箱や本のページに出ているものを読んでテキストログ（記録のファイル）に記録することと、案内の矢印や枠を表示することをします。放置して何かを進める処理もありません。
- 検索ページとゲームは直接つながっていません。案内は、検索ページでコピーした文字を自分でゲームに貼って始めます。
- 検索ページは、記録に書かれた文字だけを使います。

## 動く環境

- Ultima Online Enhanced Client（日本語のクライアントで確かめています）
- **CLifeUI（必須）**。公開されている版で確かめています
- Windows 10 / 11。追加で入れるものはありません（検索ページは Windows に最初から入っている PowerShell 5.1 だけで動きます）

## 入れ方（要約）

1. 2 つの zip を、それぞれ右クリック →「プロパティ」→ 下の「許可する」に印を付けて OK。それから展開します（これをしないと、検索ページを開くときに「発行元を確認できませんでした」の警告が出ます）。
2. モジュールの zip を展開してできた `ClfMods\CPlusHomeRecord` フォルダを、CLifeUI の `ClfMods` フォルダの中に入れます。
3. ゲームのフォルダの `logs` の中に、`CPlusExport` フォルダを**必ず作ります**（家の記録の専用の記録の置き場所。CLifeUI の公式の手順で作る `damage`・`animalLore` と同じ `logs` の中）。ゲームはこのフォルダを自動では作りません。無いと、チャットには記録したと出ても、ファイルは作られません。
4. （整理削除を使うなら）`CPlusExport` フォルダに書き込みの権限を付けます。`CPlusExport` フォルダを右クリック →「プロパティ」→「セキュリティ」→「編集」→ 一覧から自分の名前（Windows にサインインしている名前）を選び、「変更」の「許可」に印を付けて OK を押します。プロパティの窓に戻ったら、そこでも OK を押します（一覧に無ければ「追加」で自分の名前を足します）。権限を付けなくても、記録と検索はできます。
5. ビューアーの zip を展開してできた `CPlusHomeViewer` フォルダを、ゲームのフォルダの外の好きな場所（ドキュメントなど）に置きます。
6. ゲームを起動し、行動ウィンドウの「CPlus」から「家の記録」のアイコンをホットバーに置きます。
7. 家の敷地の向かい合う 2 か所の角（対角。たとえば北西の角と南東の角）に立って、それぞれでアイコンの右クリック →「角を足す」→「家 1」を選びます。2 か所を結んだ四角が家の範囲になります（高さは見ないので、どの階も入ります）。範囲は横も縦も一辺 40 マスまで、角は 2 か所までです（3 か所目は足せません）。同じ列や同じ行の 2 か所だと幅 1 マスの線になるので、対角を選んでください。まちがえたときや登録し直すときは、右クリック →「家を消す」で消してから、もう一度 2 か所を登録します。
8. 登録した家で、ロックダウン（またはロックダウン ＆ セキュア）した箱を開いて閉じると、その中身が記録されます。その箱の中で開いた袋や箱の中身も記録されます。家に置いただけでロックダウンしていない箱や、バックパックの中は記録しません。`CPlusHomeViewer\家の記録検索.bat` をダブルクリックすると検索ページが開きます。記録のフォルダが標準のインストール先に無いときは、検索ページが最初の 1 回だけ場所を尋ねます（ブラウザが開かないときは、自分でブラウザを開いて `http://localhost:47651/` を入れます）。

## 記録と貼り付けの行の形（自分で読み書きしたい人へ）

- 記録は文字のファイル（UTF-16LE）で、1 行目に `CPLUS_HOME_RECORD` と形式の番号（今は 2）が入ります。行の並びは、モジュールの `CPlusHomeRecord.lua` の中の説明に書いてあります。
- 検索ページの「ゲームで案内」がコピーする行は `CPLUSHOME2`、「家の範囲をゲームへ」がコピーする行は `CPLUSAREA1` で始まります。形は、モジュールの `CPlusHomeGuide.lua`・`CPlusHomeArea.lua` の中の説明に書いてあります。
