家の記録 使い方

CLifeUI に足して使う、非公式の追加機能「CPlusHomeRecord（家の記録）」と、その検索ページ「CPlusHomeViewer」の入れ方と使い方です。

CLifeUI が必須です。CLifeUI の部品を使って動くので、CLifeUI を入れていない状態や、ほかのカスタム UI では動きません。先に CLifeUI を入れて、動くことを確かめてから入れてください。CLifeUI は、作者様の公式ページ（https://uo.clife.work/uosa-custom-ui-clifeui/）の手順で入れてください。

1. これは何か

自分の家でロックダウン（またはロックダウン & セキュア）した箱を開いて閉じると、その中身をファイルに記録します。箱の中で開いた袋や箱の中身も記録します。記録は PC のブラウザで開く「家の記録 検索」のページで探せます。

  • アイテムの名前、プロパティ（説明の行）、家、階、箱の種類で探せます。
  • 宝石箱・パワースクロールブック／超越のスクロールブック・デイビーズのロッカーの中身も記録します。
  • 見つけたアイテムの「ゲームで案内」を使うと、ゲームの中で、目的の箱の上に矢印が出て、箱を開くと次のマスが光ります。

配る物は 2 つの zip に分かれています。

CPlusHomeRecord-0.3.zipゲームの中で記録する部分（モジュール）。CLifeUI の ClfMods フォルダの中に入れます。
CPlusHomeViewer-0.3.zip記録を探す検索ページと、その読み出し役（ビューアー）。ゲームのフォルダの外の、好きな場所（ドキュメントなど）に置きます。

3. 動く環境

ゲームUltima Online Enhanced Client。日本語のクライアントで確かめています。
カスタム UICLifeUI（必須）。公開されている版で確かめています。家の記録は CLifeUI の部品を使うので、CLifeUI が無いと動きません。
WindowsWindows 10 / 11（Home でも Pro でも）。追加で入れるものはありません。検索ページは、Windows に最初から入っている PowerShell 5.1 と、Windows の HTTP の仕組み（http.sys）だけで動きます。
ブラウザChrome・Edge など、新しいブラウザ（作者は Chrome と Edge で確かめています）。

4. 入れ方

  1. 2 つの zip の「許可する」に印を付けてから展開します。それぞれの zip を右クリック →「プロパティ」→ 下の「セキュリティ: 許可する」に印を付けて OK。こうしないと、ネットから来たファイルとして、検索ページを開くときに警告が出ます。もし「発行元を確認できませんでした。このソフトウェアを実行しますか?」の警告が出たら、［実行］を押せば開けます。毎回出さないようにするには、zip の「許可する」からやり直してください。
  2. モジュールを CLifeUI の中に入れます。CPlusHomeRecord-0.3.zip を展開してできた ClfMods\CPlusHomeRecord を、CLifeUI の ClfMods フォルダの中に入れます。 
    C:\Program Files (x86)\Electronic Arts\Ultima Online Enhanced\
  UserInterface\
    <CLifeUI のフォルダ>\    ← 名前は自由（公式の手順では ClifeUI-master）
      ClfMods\
        ClfCommon\          ← CLifeUI のもの
        …
        CPlusHomeRecord\    ← ここに入れる（フォルダごと）
  logs\
    damage\                 ← CLifeUI の公式の手順で作るフォルダ
    animalLore\             ← 同上
    CPlusExport\              ← 家の記録の記録が入るフォルダ（自分で作る）
    Program Files の下なので、コピーのときに管理者の確認が出ます。
  3. 記録のフォルダを作ります。…\Ultima Online Enhanced\logs の中に CPlusExport フォルダを作ります。家の記録の専用のフォルダです（CLifeUI の公式の手順で作る damage・animalLore フォルダと同じ logs の中）。必ず作ってください。ゲームはこのフォルダを自動では作りません。無いと、チャットには「家の記録: …」と記録したように出ても、ファイルは作られず、エラーも出ません。検索ページを開くと赤い枠で知らせるので、そこで気づけます。フォルダを作れば、検索ページはそのまま回復します（それまでの記録は残っていません）。
  4. （検索ページで記録を消すなら）記録のフォルダに書き込みの権限を付けます。検索ページで記録を消す（［整理削除］、箱の一覧の［記録を消す］、名前の設定の［この家の記録を消す］）には、あなたの Windows のアカウントに、このフォルダの「変更」の権限が要ります。CPlusExport フォルダを右クリック →「プロパティ」→「セキュリティ」→「編集」→ 一覧から自分の名前（Windows にサインインしている名前）を選び、「変更」の「許可」に印を付けて OK を押します。プロパティの窓に戻ったら、そこでも OK を押します（一覧に無ければ「追加」で自分の名前を足します）。権限を付けなくても、記録と検索はできます。
  5. ビューアーを好きな場所に置きます。CPlusHomeViewer-0.3.zip を展開してできた CPlusHomeViewer フォルダを、ゲームのフォルダの外の好きな場所（ドキュメントなど）に置きます。フォルダ 1 つにまとまっているので、そのまま置けば済みます。
  6. ゲームを起動します。ログインすると、チャットに CPlusHomeRecord : initialized (ON) と出ます。

5. ゲームでの使い方

アイコンをホットバーに置く

行動ウィンドウの分類「CPlus」に、2 つのアイコンがあります。ホットバーに置いて使います。

家の記録（家/記録）左クリックで、登録した家と記録の状態を表示します。右クリックで、家の登録・記録の ON/OFF・範囲の貼り付けのメニューが出ます。
家検索検索ページの「ゲームで案内」でコピーした文字を貼る窓を開きます。

家を登録する

  1. 家の敷地の角に立ちます。
  2. 「家の記録」アイコンを右クリック →「角を足す」→「家 1」。
  3. 向かい合う角（対角）にも立って、同じく「角を足す」→「家 1」。2 か所を結んだ四角が家の範囲になります（高さは見ません）。範囲は横も縦も一辺 40 マスまで、角は 2 か所までです（3 か所目は足せません）。同じ列や同じ行の 2 か所だと幅 1 マスの線になるので、対角を選んでください。登録し直すときは、右クリック →「家を消す」で消してから、もう一度 2 か所を登録します。
  4. アイコンを左クリックして、範囲が合っているか確かめます。

家は 9 軒まで登録できます。登録はキャラクターごとです。まちがえたら、右クリック →「家を消す」でやり直します。

記録する

登録した家の中で、ロックダウンした箱を開いて閉じると、閉じたときに記録されます。チャットに 家の記録: 家 1: … と出ます。家の範囲の外では何もしません。

宝石箱など開いている間に見えたページのアイテムだけを記録します。全部のページをめくってから閉じてください。
スクロールブック本を開いて、技能のページを自分で開きます。開いたページの本数を控え、本を閉じたときに記録します。1 回で全部の技能を開かなくても、何回かに分けて開いた分を合わせて見ます。スクロールを出し入れしたときは、その技能のページを開き直してください。ロックダウンした本か、ロックダウンした箱の中の本を記録します（バックパックの中の本は記録しません）。
デイビーズのロッカー開いている間に見えたページの地図と SOS を記録します。

記録を止めたいときは、右クリック →「記録 ON/OFF」。

6. 検索ページの使い方

開き方

CPlusHomeViewer\家の記録検索.bat をダブルクリックします。デスクトップにショートカットを作っておくと便利です。

  • ブラウザで「家の記録 検索」のページが開きます。ブラウザが自動で開かないときは、自分でブラウザを開いて、アドレス欄に http://localhost:47651/ を入れてください。
  • タスクバーに、最小化された PowerShell の窓（題名「家の記録 検索（閉じると検索ページが止まります）」）が出ます。これが読み出し役です。この窓を閉じると検索ページが止まります。
  • 止め方は 2 つです。① 検索ページを閉じてから 10 分待つと、自動で止まります。② すぐ止めたいときは、タスクバーの PowerShell の窓（題名「家の記録 検索（閉じると検索ページが止まります）」）を自分で閉じます。

記録のフォルダ

検索ページは、まず標準のインストール先の記録のフォルダ（C:\Program Files (x86)\Electronic Arts\Ultima Online Enhanced\logs\CPlusExport）を見ます。

  • ゲームのフォルダはあって CPlusExport が無いときは、作るように案内します。作れば、そのまま読めるようになります。
  • ゲームを別の場所に入れているときは、最初の 1 回だけ場所を尋ねます。エクスプローラーでゲームのフォルダか CPlusExport フォルダを開き、アドレス欄のパスをコピーして、検索ページの欄に貼り、［決める］を押してください。
  • 決めた場所は覚えておきます（%LOCALAPPDATA%\CPlusHomeSearch\home_settings.json）。見出しの［変える］で、あとから変えられます。

受け付けるのは、CPlusExport という名前のフォルダだけです（ゲームのフォルダを貼ったときは、その中の logs\CPlusExport）。読み出し役が消すのも、そのフォルダの中の記録の名前のファイルだけです。

タブ

検索左の条件で絞り込みます。アイテム名、説明の言葉（一覧に無いプロパティ）、家と階、プロパティの数値、箱の種類（宝石箱・スクロールブックなど）。見つけたアイテムのカードの［ゲームで案内］で、ゲームへ貼る文字をコピーします。
開きに行くリストまだ中身を記録していない入れ物や、全部のページを読めていない宝石箱・本の一覧です。最後まで読み込まれていないスクロールブックは、本ごとに「読み込んだ技能 N / 全 M」と出ます。
名前の設定家・階・箱に名前を付けます。キャラクターの割り当てと、家の範囲をゲームへコピーするのもここです。
箱の一覧床に置いた箱の一覧です（箱の中の袋は、その箱の「中の数」に入ります）。家を選んだり、文字で絞ったりできます。箱ごとに最後の記録の日時が出ます。検索のカードの［箱の一覧で見る］から、その品の入っている箱へ移れます。

最初にすること: キャラクターの割り当て

記録には、書いたキャラクターの番号が入っています。「名前の設定」の「キャラクターの割り当て」で、番号ごとに、どのアカウント・シャードのキャラクターかを決めてください。候補はゲームの設定のフォルダ（User Data）から探して出ます。押して決めるまで確定しません。決めるまで、その記録は「全部を見る」でだけ出ます。

ゲームで案内

  1. 検索ページでアイテムのカードの［ゲームで案内］を押します（案内の文字がコピーされます）。
  2. ゲームで「家検索」アイコンを押し、開いた窓に貼り付けて Enter。
  3. 目的の箱の上に赤紫の矢印が出ます。箱や袋を開くと、次に開くマスが赤紫の枠で光ります（グリッド表示のとき）。もう一度アイコンを押すと、窓と案内が消えます。

家の範囲をほかのキャラクターへ

「名前の設定」の「家の範囲をゲームへ」で 1 行コピーし、ゲームで「家の記録」アイコンを右クリック →「範囲を貼る」の窓に貼って Enter を押すと、そのキャラクターにも同じ番号で家が登録されます。

整理削除

このソフトはデータベースを使いません。箱を閉じるたびに、その箱の記録ファイルが 1 本増えます（1 本はふつう数 KB、大きな箱でも数十 KB。記録 1,000 本でおよそ 8 MB）。検索ページは、箱ごとにいちばん新しい記録を使うので、同じ箱の古い記録は使われないまま、たまっていきます。ときどき整理削除で消してください。

見出しの［整理削除］を押すと、古い記録を消します。今の検索の結果に使われていない古い記録だけを消し、使われている古い記録（読みかけのスクロールブックや宝石箱の前の記録など）は残します。確認の帯の［消す］を押したときだけ消えます。消した記録は元に戻せません。

箱や家の記録を消す

家がなくなったときや、箱のロックダウンを解除したときは、その箱を開いても新しい記録はできないので、最後の記録が残り続けます。箱の一覧では、最後の記録が 30 日より前の箱の日時が赤く出るので、目安にしてください。

  • 箱の記録を消す: 箱の一覧の［記録を消す］を押すと、その箱と、中の袋の記録をすべて消します（古い記録も含みます）。ふだんは確認を出しません。同じシャードのほかの組でも記録している箱は、確認のあと、ほかの組の分も消します。箱に付けた名前は残ります。箱がまだあれば、開いて閉じると記録し直されます。デイビーズのロッカーは家ごとに 1 つにまとめています。［記録を消す］を押すと、その家のロッカーの記録がすべて消えます。
  • 家の記録を消す: 名前の設定の家の枠の［この家の記録を消す］を押すと、箱の数と記録の本数を出して確かめます。［消す］を押すと、その家の箱の記録をすべて消し、家の範囲と、家と階の名前も外します。消せない記録が残ったときは、家の範囲と名前は外さないので、もう一度押してください。箱が 1 つも無くなった家も、組を選んでいるときは名前の設定に枠が出るので、そこから外せます。箱の一覧で家の最後の箱を消したときは、帯でお知らせします。消すのは選んでいる組の家だけです。ほかの組でも同じ家を記録しているときは、帯に出るので、その組を選んで同じように消してください。
  • ゲームの中の家の登録は残るので、その家を登録した各キャラクターで、「家の記録」アイコンを右クリック →「家を消す」をしてください。
  • まだどのキャラクターか決めていない番号の記録は、どの組のものか分からないので消しません。残っているときは帯で本数を知らせるので、名前の設定で割り当ててから、もう一度消してください。
  • 読めない記録（書きかけで止まったものなど。上の帯に「読めない記録が N 本」と出るもの）は、ページからは消せません。消すときは、記録の CPlusExport フォルダの中のそのファイルを、エクスプローラーで消してください。
  • 割り当てられない番号（キャラクターを消したなどで、候補に出ない番号）の記録も、ページからは消せません。同じように、記録のフォルダの中のそのファイルをエクスプローラーで消してください。
  • 検索ページは 1 つの窓（タブ）だけで開いてください。2 つ開いていると、片方で名前を保存したときに、もう片方で外した家の範囲や名前が戻ることがあります。
  • どちらも、見出しの「組」で組を選んでいるときだけ消せます（「全部を見る」では消せません）。整理削除と同じく、記録のフォルダの書き込みの権限が要り、消した記録は元に戻せません。

7. 安全について

ゲームに対してしないこと

  • ゲームのクライアントを書き換えません。Enhanced Client が公式に用意しているカスタム UI の仕組みの中で動きます。
  • ゲームのメモリを外から読んだり書いたりしません。
  • ゲームとサーバの間の通信を、読んだり書き換えたりしません。このソフトからサーバへ何かを送ることもありません。
  • ゲームの操作を自動で行いません。ボタンを押す・アイテムを使う・キャラクターを動かすといった操作はせず、家の中の開いた箱や本のページに出ているものを読んでテキストログ（記録のファイル）に記録することと、案内の矢印や枠を表示することをします。放置して何かを進める処理もありません。
  • 検索ページとゲームは直接つながっていません。案内は、検索ページでコピーした文字を自分でゲームに貼って始めます。
  • 検索ページは、記録に書かれた文字だけを使います。

検索ページの読み出し役がすること

検索ページの読み出し役（home_search_server.ps1）がすること・しないことです。

待ち受けhttp://localhost:47651/ で待ち受け、この PC の中からの要求にだけ答えます。ほかの PC からの要求は断ります。
読むもの記録のフォルダの記録、名前と設定のファイル、User Data のフォルダとファイルの名前（キャラクターの割り当ての候補に使う。ファイルの中身は読みません）。
書くもの読み出し役が書くのは、名前と設定のファイル（%LOCALAPPDATA%\CPlusHomeSearch の home_names.json・home_settings.json）だけです。ゲームの中の部分は、記録を記録のフォルダに書き、家の範囲と記録の ON/OFF をゲームの設定として保存します。ブラウザは、表示の設定（明るさなど）をそのブラウザに保存します。
消すもの消すのは、次のボタンを押したときだけです: ［整理削除］→［消す］（古い記録）、箱の一覧の［記録を消す］（その箱と中の袋の記録。同じシャードのほかの組でも記録している箱は、確認のあと、ほかの組の分も）、名前の設定の［この家の記録を消す］→［消す］（その家の記録）。
外への通信ありません。ほかのサイトのページから、読み出し役の答えを読んだり、名前を書かせたり記録を消させたりはできません（送り元と宛先を確かめ、ほかのページの枠にも入れさせません）。
止まり方止め方は 2 つです。① 検索ページを閉じてから 10 分待つと、自動で止まります。② すぐ止めたいときは、タスクバーの PowerShell の窓（題名「家の記録 検索（閉じると検索ページが止まります）」）を自分で閉じます。

家の記録検索.bat は PowerShell を -ExecutionPolicy Bypass で起動します。これは、この起動のときだけスクリプトの実行の制限を外す指定で、PC の設定は変えません。スクリプトの実行を許していない PC でも、この起動のときだけ動かすために必要です。中身は文字のファイルなので、メモ帳などで開いて確かめられます。

配布前の検査: 配る zip は、公開する前に ESET で検査しています。検査した日と検出エンジンの版、zip の SHA-256 は、GitHub のリリースの説明に書いてあります。

8. アンインストール

  • 先にホットバーから 2 つのアイコンを外します（残すと、押しても何も起きないアイコンになります）。
  • CLifeUI の ClfMods\CPlusHomeRecord フォルダを消します。次の起動から読み込まれません。
  • ビューアーの CPlusHomeViewer フォルダを消します。
  • 記録を消すなら、…\Ultima Online Enhanced\logs\CPlusExport フォルダを消します（家の記録の専用のフォルダです）。
  • 名前と、覚えた記録のフォルダの場所を消すなら、%LOCALAPPDATA%\CPlusHomeSearch フォルダを消します。
  • 記録と名前のファイルは、消しても消さなくてもゲームには影響しません（ゲームはこれらを読みません）。家の範囲と記録の ON/OFF の値はゲームの設定に残りますが、使われなくなるだけです。

ゲームの設定に残るもの

家の記録は、次の値をゲームの設定に保存します。フォルダを消しても残りますが、読む物が無くなるので、ゲームの動きには影響しません。

キャラクターごとの設定のファイル: ドキュメント\EA Games\<ゲームの名前>\User Data\<アカウント>\<シャード>\<キャラクター名>（拡張子の無い XML のファイル）

ファイルの中の場所名前中身
CharacterSettings → Options → UIVariables の BoolVarCPlusHomeRecordEnable記録の ON/OFF（true／false。無ければ ON）
同じ所の NumberVarCPlusHomeRecordHouse<n>Facet・…MinX・…MaxX・…MinY・…MaxY・…Corners（n は家の番号 1〜9）家 n の範囲。マップの番号、東西と南北の最小と最大、足した角の数（0 なら未登録）。家 1 軒につき 6 つ
CharacterSettings → Interface → WindowSettings の WindowPositionsCPlusHomeGuideWindow・CPlusHomeAreaWindow家検索の窓と、範囲を貼る窓の位置（動かしたときだけ）
CharacterSettings → Interface → Hotbars の UserActionid が 6029・6030ホットバーに置いたアイコン（ホットバーから外せば消えます）

ほかに、ゲームがモジュールごとに作る User Data\CPlusHomeRecord\ModSettings.xml が残ります。中身は、モジュールが有効かどうかと、最後に読んだ版だけです（このファイルは丸ごと消してかまいません）。

キャラクターの設定のファイルは、ほかの UI の設定と同じファイルなので、手で書き換えるのはおすすめしません。書き換えるなら、ゲームを閉じてから、ファイルをコピーしたうえで行ってください。

9. メモリ使用量について（作者の環境での実測）

動くとき記録が動くのは、登録した家の範囲の中で箱を開け閉めしたときだけです。家の外では何もしません。常に動いている処理（定期処理）は持ちません。案内している間だけ 2 秒おきに箱の場所を見直します。
ゲームのメモリ記録の書き出しで増えるのは、箱を 1 回閉じるあたり 0.2 MB 以下で、ふだんの揺れに埋もれる大きさでした。案内の見直し（3 分）と、家検索の窓の開け閉め（10 回）では増えませんでした。
なお、箱を開けると、ゲーム自身が中身の情報を蓄えます。初めて開く箱ほどゲームのメモリは増えますが、これは家の記録の有無とは関係ありません。
読み出し役PowerShell 自体で約 90 MB、記録 1,000 本余りを検索ページに渡したあとで約 120 MB でした。検索ページを閉じてから 10 分待つと自動で止まり、そのあとは動いていません（すぐ止めたいときは、PowerShell の窓を自分で閉じます）。
記録の大きさ1 本はふつう数 KB、大きな箱でも数十 KB。記録 1,000 本でおよそ 8 MB です。

10. 注意点・細かい仕様

  • 記録はたまっていきます。箱を閉じるたびに記録ファイルが 1 本増え、検索ページは箱ごとにいちばん新しい記録を使います。古い記録は［整理削除］で消してください。
  • 記録は箱を開いたときだけ取れます。開かない箱の中身は記録できません。
  • 新しいアイテムやプロパティ: アイテムの名前と説明の文は、ゲームが表示している文をそのまま記録するので、新しいものも「アイテム名」「説明の言葉」で探せます。左の条件の選択欄は決まった一覧なので、新しいプロパティは出ません（「説明の言葉」で探してください）。
  • パブリッシュの影響: 宝石箱・デイビーズのロッカー・スクロールブックは、ゲームの画面の並びを読んでいます。パブリッシュで画面が変わると、読めなくなることがあります。
  • 確かめていない入れ物: ベテラン報奨の物置小屋・ポーション貯蔵槽など、作者が持っていない一部の入れ物は、動作を確かめていません。
  • アカウントとシャード: 記録はアカウントとシャードの組ごとに分けて見られます（見出しの「組」）。
  • Windows の警告: 家の記録検索.bat を開いたときに「発行元を確認できませんでした」の警告が出るのは、zip の「許可する」をせずに展開したときです。もし「発行元を確認できませんでした。このソフトウェアを実行しますか?」の警告が出たら、［実行］を押せば開けます。毎回出さないようにするには、zip の「許可する」からやり直してください。「スマート アプリ コントロール」が有効な PC で止められるかは、作者は確かめていません。
  • ポート 47651: ほかのソフトがこの番号を使っていると、検索ページを始められません（そう知らせます）。
  • 記録と貼り付けの行の形: 記録は文字のファイル（UTF-16LE）で、1 行目に CPLUS_HOME_RECORD と形式の番号（今は 2）が入ります。行の並びはモジュールの CPlusHomeRecord.lua の中の説明にあります。「ゲームで案内」がコピーする行は CPLUSHOME2、「家の範囲をゲームへ」がコピーする行は CPLUSAREA1 で始まり、形は CPlusHomeGuide.lua・CPlusHomeArea.lua の中の説明にあります。
