# CPlusHomeViewer（家の記録 検索）

「家の記録」（CPlusHomeRecord）がゲームの中で書いた記録を、PC のブラウザで探すための検索ページです。ゲームの中で記録するモジュール（`CPlusHomeRecord-0.3.zip`）と組で使います。モジュールは CLifeUI に足して使うので、**CLifeUI が必須です。**

**詳しい入れ方と使い方は、このフォルダの `使い方.html` をブラウザで開いてください。**

## 置き場所

この `CPlusHomeViewer` フォルダを、ゲームのフォルダの外の好きな場所（ドキュメントなど）に置きます。zip は、展開する前に右クリック →「プロパティ」→ 下の「許可する」に印を付けて OK してください（しないと、開くときに「発行元を確認できませんでした」の警告が出ます）。

## 開き方

`家の記録検索.bat` をダブルクリックします。ブラウザで「家の記録 検索」のページが開きます（開かないときは、自分でブラウザを開いて `http://localhost:47651/` を入れます）。

タスクバーに、最小化された PowerShell の窓が出ます。これが記録を読んでページに渡す読み出し役です。検索ページを閉じてから 10 分待つと、自動で止まります。すぐ止めたいときは、その窓を自分で閉じます。

## 記録のフォルダ

記録は、ゲームのフォルダの `logs\CPlusExport` にあります。検索ページは、まず標準のインストール先（`C:\Program Files (x86)\Electronic Arts\Ultima Online Enhanced\logs\CPlusExport`）を見ます。

- そこに `CPlusExport` フォルダが無いときは、作るように案内します（ゲームはこのフォルダを自動では作りません）。
- ゲームを別の場所に入れているときは、最初の 1 回だけ場所を尋ねます。エクスプローラーでゲームのフォルダか `CPlusExport` フォルダを開き、アドレス欄のパスをコピーして検索ページの欄に貼り、［決める］を押してください。
- 決めた場所は覚えておきます。見出しの［変える］で、あとから変えられます。

受け付けるのは、`CPlusExport` という名前のフォルダだけです（ゲームのフォルダを貼ったときは、その中の `logs\CPlusExport`）。読み出し役が消すのも、そのフォルダの中の記録の名前のファイルだけです。

検索ページの［整理削除］で古い記録を消すには、`CPlusExport` フォルダに書き込みの権限が要ります（Program Files の下なので、最初は読むことしかできません）。`CPlusExport` フォルダを右クリック →「プロパティ」→「セキュリティ」→「編集」→ 一覧から自分の名前を選び、「変更」の「許可」に印を付けて OK を押します。プロパティの窓に戻ったら、そこでも OK を押します（一覧に無ければ「追加」で足します）。権限を付けなくても、記録と検索はできます。

## 読み出し役がすること・しないこと

- `http://localhost:47651/` で待ち受け、この PC の中からの要求にだけ答えます。PC の外へは通信しません。
- 読むもの: 記録のフォルダの記録、名前と設定のファイル、ゲームの設定のフォルダ（User Data）のフォルダとファイルの名前（キャラクターの割り当ての候補に使う。ファイルの中身は読みません）。
- 書くもの: 名前と設定のファイル（`%LOCALAPPDATA%\CPlusHomeSearch` の `home_names.json`・`home_settings.json`）だけです。
- 消すもの: ［整理削除］→［消す］を押したときだけ、記録のフォルダの古い記録を消します。

`家の記録検索.bat` は PowerShell を `-ExecutionPolicy Bypass` で起動します。この起動のときだけスクリプトの実行の制限を外す指定で、PC の設定は変えません。中身は文字のファイルなので、メモ帳などで開いて確かめられます。

## アンインストール

この `CPlusHomeViewer` フォルダを消します。名前と、覚えた記録のフォルダの場所も消すなら、`%LOCALAPPDATA%\CPlusHomeSearch` フォルダを消します。どちらもゲームには影響しません。
